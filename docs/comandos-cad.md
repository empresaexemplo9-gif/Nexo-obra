# Comandos CAD

| Comando | Sintaxe | Resultado |
|---|---|---|
| `L` | `L x1,y1 x2,y2` | Cria uma linha/parede |
| `C` | `C x,y raio` | Cria um círculo |
| `M` | `M dx,dy` | Move a seleção |
| `CO` | `CO dx,dy` | Copia a seleção |
| `RO` | `RO x,y graus` | Rotaciona a seleção |
| `SC` | `SC x,y fator` | Escala a seleção |
| `E` | `E` | Cancela a seleção |

O eixo Y digitado segue a convenção de desenho técnico: valores positivos apontam para cima.
