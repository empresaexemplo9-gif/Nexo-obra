# Fontes servidas pela interface

Arquivos `.woff2` variáveis, subconjuntos latin e latin-ext, publicados pelo Google Fonts.

| Arquivo | Família | Eixo de peso | Licença |
| --- | --- | --- | --- |
| `jost-latin.woff2`, `jost-latin-ext.woff2` | Jost | 300–700 | SIL Open Font License 1.1 |
| `cormorant-latin.woff2`, `cormorant-latin-ext.woff2` | Cormorant | 300–600 | SIL Open Font License 1.1 |

O texto integral da licença de cada família acompanha os arquivos, como a própria OFL exige:
`OFL-Jost.txt` e `OFL-Cormorant.txt`. A licença permite uso, incorporação e redistribuição em
produtos comerciais, inclusive servindo os arquivos a partir do próprio domínio. Não renomeie os
arquivos para "Barium" ou "Ador Hairline": a OFL proíbe redistribuir a fonte sob o nome reservado
de outra família.

São as substitutas livres das fontes do manual da marca. Ao receber os arquivos licenciados de
Barium e Ador Hairline, troque os `src` das regras `@font-face` em `app/globals.css` e remova
estes arquivos. Ver `docs/HOIKOS-IDENTITY.md`.
